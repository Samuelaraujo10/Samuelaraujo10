## 👨‍💻 Sobre Mim

Sou um **Desenvolvedor Full-Stack** focado no ecossistema **JavaScript**, construindo desde interfaces modernas, responsivas e orientadas à experiência do usuário (**React, Vite, Tailwind CSS**) até APIs RESTful e sistemas back-end robustos (**Node.js, Express, SQLite, MongoDB e Firebase**).

- 🚀 Experiência prática no desenvolvimento de **aplicações ponta a ponta**: sistemas de delivery em tempo real, gestão de acervos escolares e catálogos inteligentes integrados com IA.
- 🏗️ Foco em **arquitetura limpa**, autenticação segura (JWT/Bcrypt/Firebase Auth), integração de serviços externos (Pix BR Code, WhatsApp Web, Google Cloud Vision) e modelagem de dados relacional e NoSQL.
- 🌱 Em constante evolução técnica em desenvolvimento **Full-Stack moderno** e boas práticas de engenharia de software.
